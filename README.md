# Multporn Paperback

A TypeScript starter extension targeting Paperback 0.9. No source requests, parsing, or scraping are implemented yet.

## Requirements

- Node.js 24 or newer
- npm

## Development

```sh
npm install
npm run typecheck
npm run bundle
npm run serve
```

Replace the placeholder icon in `src/MultpornPaperback/static/icon.png` before publishing. The extension manifest and entry point live in `src/MultpornPaperback/`.

The SDK and CLI are pinned to the Paperback 0.9 toolchain release line.
